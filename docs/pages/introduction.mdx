# Puzzle API

The Puzzle external REST API gives partners programmatic access to companies,
accounts, transactions, bills, invoices, reports, and more.

- **Base URL:** `https://api.puzzle.io/rest/v0`
- **Format:** JSON requests and responses
- **Reference:** the full endpoint reference is under [API Reference](/api),
  generated from the same contracts the API is served from — it always
  describes the deployed API.

## Authentication

The API uses **OAuth 2.0**. Obtain an access token, then send it as a bearer
token on every request:

1. Start the Authorization Code flow (with PKCE) at `GET /oauth/authorize`.
2. Exchange the authorization code at `POST /oauth/token`
   (`application/x-www-form-urlencoded`; confidential clients may
   authenticate with HTTP Basic). The same endpoint refreshes tokens.
3. Call the API with the access token:

```bash
curl https://api.puzzle.io/rest/v0/accounts?companyId=<company-id> \
  -H "Authorization: Bearer <access-token>"
```

See the **OAuth** section of the [API Reference](/api) for the full
parameter details of both endpoints.

## Trying endpoints

Every operation page in the reference shows a ready-to-copy request (curl and
other languages). Paste your bearer token into the `Authorization` header and
run it against the base URL above.
