# Write Endpoints

We are currently developing a series of write endpoints to allow our API partners to create data in Puzzle! 

All of these endpoints are currently in beta and are subject to change. We are planning on making continuous updates and improvements to these endpoints over time, but they are currently stable and ready to use.

If you are interested in trying them out, please reach out to use at api@puzzle.io. We would love to hear any feedback you have!

### Requirements
In order to use Puzzle's write API, you will need to do the following:

- Reach out to api@puzzle.io to create/update your API keys
  - If you DO NOT already have Puzzle API keys, we will create new ones for you. See [Getting Started](docs/Getting-started-v2.md) for more details. 
  - If you DO already have Puzzle API keys, we will need to update them to allow access to the write API. The keys themselves will not change. 
- You must use our OAuth authentication. If you are still using the deprecated link token authentication, you will need to migrate to OAuth in order to use the write API. 
- Once your API keys have been updated, all you need to do is include the `write:___` [scopes](docs/Scopes.md) in your authorization request, then you can begin creating data in Puzzle!
