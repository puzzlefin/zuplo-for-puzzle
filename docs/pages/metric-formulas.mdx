# Metrics

We provide a number of metrics in our API and this document explains how each of those metrics is calculated and which endpoint provides it.

| Metric Name                                    | How it's calculated                                                                                                                                                           | Where to get it                                                                                                     |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `annualAvgFullyLoadedSalaryCostPerEmployee`    | ( Average salary cost + cost burden (Employer taxes, benefits, etc) ) divided by total number of employees for the past 12 months.                                            | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `annualAvgSalaryCostPerEmployee`               | Average salary cost divided by total employees for the past 12 months.                                                                                                        | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `lastMonthAvgFullyLoadedSalaryCostPerEmployee` | ( Average salary cost + cost burden (Employer taxes, benefits, etc) ) divided by total number of employees for the last month.                                                | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `lastMonthAvgSalaryCostPerEmployee`            | Average salary cost divided by total number of employees for the last month.                                                                                                  | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `totalCash`                                    | Sum of the cash balance of all the cash accounts for the company, including manually added accounts (last known reconciled balance is included) as of today.                              | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `lastMonthBankBurn`                            | Cash difference between end of the last day of the previous month and end of the last day of the last month.  (ex: Bank balances on Dec 31st - Jan 31st is Bank Burn for Feb) | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `runway`                                       | The projected number of months to fully cover expenses, `totalCash` divided by `lastMonthTotalBurn`.                | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `fundraiseDate`                                | 6 months before `cashOutDate`.                                                                                                                                                | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `cashOutDate`                                  | The last day of last fully funded month as determined by `runway`.                                                                                                                                      | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `lastMonthOperatingBurn`                       | Difference between operating income and operating expense (cash-in from ops and cash-out from ops).                                                                           | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `lastMonthTotalBurn`                           | Difference between total cash-in and total cash-out (total cash-in and total cash-out).                                                                                       | [Company](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/81mletis3s9ij-get-company-with-metrics)                   |
| `averageFullyLoadedSalaryCostPerEmployee`      | ( Average salary cost + cost burden (Employer taxes, benefits, etc) ) divided by total number of employees for the requested month.                                           | [Employee Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/76d022b7e3a9a-employee-metrics) |
| `averageSalaryCostPerEmployee`                 | Average salary cost divided by total number of employees for the requested month.                                                                                             | [Employee Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/76d022b7e3a9a-employee-metrics) |
| `totalFullyLoadedSalaryExpense`                | ( Average salary cost + cost burden (Employer taxes, benefits, etc) ) for the requested month.                                                                                | [Employee Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/76d022b7e3a9a-employee-metrics) |
| `totalSalaryExpense`                           | Average salary cost for the requested month.                                                                                                                                  | [Employee Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/76d022b7e3a9a-employee-metrics) |
| `totalExpenses`*                               | The sum of all the Expense accounts.                                                                                                                                          | [Expense Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/8633d162662b5-expense-metrics)   |
| `totalOperatingExpenses`*                      | The sum of all the operating expenses.                                                                                                                                        | [Expense Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/8633d162662b5-expense-metrics)   |
| `annualizedRevenue`                            | `totalRevenue` for the last month multiplied by 12.                                                                                                              | [Revenue Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/65215133beafc-revenue-metrics)   |
| `totalRevenue`*                                | The sum of all the Revenue accounts.                                                                                                                                          | [Revenue Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/65215133beafc-revenue-metrics)   |
| `totalCostOfRevenue`*                          | The sum of all the costs associated with earning the revenue.                                                                                                                 | [Revenue Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/65215133beafc-revenue-metrics)   |
| `totalGrossProfit`*                            | Total cost of goods sold, `totalRevenue` - `totalCostOfRevenue`.                                                                                                                             | [Revenue Metrics](https://puzzle-financial.stoplight.io/docs/puzzle-accounting-api/65215133beafc-revenue-metrics)   |

`*` denotes a standard accounting metric
